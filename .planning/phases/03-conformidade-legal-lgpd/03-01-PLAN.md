<objective>
Ship the cookie-consent vertical slice end to end (LEGAL-03): a visitor sees a sober fixed bottom banner on first visit, the three tracking scripts (GA4 / Meta Pixel / Clarity) stay suppressed until the visitor decides, and the choice persists for 6 months.

Purpose: The site currently injects tracking scripts unconditionally (`app/layout.tsx` renders `<TrackingScripts />` with no gate), which is not LGPD-compliant. This plan makes tracking conditional on explicit consent.

Output: `ConsentProvider` (consent state + localStorage), `CookieBanner` (UI), a gated `TrackingScripts`, consent constants in `lib/site.ts`, and a rewired `layout.tsx`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| visitor browser → first-party localStorage | Consent choice is stored client-side; tamperable by the visitor, but only affects their own tracking state (acceptable). |
| visitor → third-party tracking scripts (GA4/Meta/Clarity) | Third-party scripts execute in the page only after consent; pre-consent they must not load. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | localStorage consent value | accept | Visitor can edit their own consent; impact limited to their own tracking. No server trust placed on it; nothing sensitive stored. |
| T-03-02 | Information Disclosure | TrackingScripts firing pre-consent | mitigate | `if (!consent) return null` gate ensures GA4/Meta/Clarity never mount before explicit consent (LGPD core). Verified in Task 3 step 2. |
| T-03-03 | Repudiation | consent choice not persisted | mitigate | Choice written to localStorage with a 6-month `expiresAt`; banner suppressed while valid (D-07/D-08). |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed this phase (no install tasks); uses existing React + next/link + existing hook. Audit table not required. |
</threat_model>
