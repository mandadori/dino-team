## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| category slug (route param) -> data filter | Dynamic [slug] param drives a content filter |
| breadcrumb data -> JSON-LD <script> | Structured-data strings injected into category pages |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-09 | Tampering | category [slug] param | mitigate | generateStaticParams enumerates only the 4 fixed CATEGORIES; any other slug hits notFound() (404). No arbitrary filesystem path derived from the param. |
| T-04-10 | Information Disclosure/XSS | BreadcrumbList JSON-LD | mitigate | Emitted through <JsonLd> (Wave-2 primitive) which applies .replace(/</g,"\\u003c"); no hand-serialized script tags. |
| T-04-11 | Tampering | canonical/breadcrumb URLs | mitigate | All absolute URLs derive from SITE_URL (build-time env); category slug constrained to the 4-enum. |
</threat_model>
