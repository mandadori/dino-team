# Ângulos queimados

## Estrutura

Cada entrada:

```
- **<slug-do-ângulo>** — última publicação: YYYY-MM-DD
  - Resumo do ângulo: 1 linha
  - Janela de descanso recomendada: <N dias / N semanas>
  - Pode voltar a partir de: YYYY-MM-DD
```
