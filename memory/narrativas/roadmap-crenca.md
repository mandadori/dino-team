# Roadmap de crença

O que o público deve crer a cada horizonte. Três crenças em sequência, ancoradas na espinha filosófica (direção → caminho → identidade). Populado na Onda 2.

## 3 meses

- O resultado invisível não é ausência de progresso — é a parte do processo que ninguém posta.
- Medir pelo espelho é medir errado; o processo funciona antes de aparecer.

## 6 meses

- Direção vence intensidade: quem sustenta o caminho chega; quem troca de método a cada dúvida acumula recomeços.
- O problema não é falta de esforço — é falta de direção. Com direção correta, o resultado é consequência.

## 12 meses

- Quem você se tornou no caminho é o prêmio — não a foto, não o reconhecimento.
- Identidade não se declara: é a escolha repetida na mesma direção. O leitor que chegou aqui já é outra pessoa.
